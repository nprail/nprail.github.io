# Images Directory

This directory contains photos and media for the portfolio website.

## Directories

- **photography/** - General photography work
- **rockets/** - Rocket launch photography  
- **videos/** - Video thumbnails and media

## Adding Real Images

To use actual photos from Noah's portfolio:

1. **Rocket Photography**: Download images from Flickr albums featuring rocket launches
   - Example: SpaceX launches, NASA events, rocket photography
   
2. **General Photography**: Download featured photos from https://www.flickr.com/people/nprail/

3. **Video Thumbnails**: Extract thumbnails from YouTube channel https://www.youtube.com/@nprail

## Image Guidelines

- Use WebP format for best performance
- Optimize images before adding (compress, resize appropriately)
- Square images for photography grid: 800x800px
- Video thumbnails: 16:9 aspect ratio, 1280x720px recommended
- Keep file sizes under 500KB per image
